## 2. Hook I/O contract (AGY hub-2.21.0)

- AGY runs each hook with `cmd /c <command>` on Windows, cwd = directory containing `hooks.json` (= `plugin/`). Commands: `node hooks/<file>.mjs`.
- stdin: one JSON object. Common fields: `conversationId`, `workspacePaths`, `transcriptPath`, `artifactDirectoryPath`, `modelName`.
- PreToolUse input adds `toolCall: {name, args}`. Output: `{"decision":"allow"|"deny", "reason": "..."}`.
- Stop input adds `executionNum`, `terminationReason`, `error`, `fullyIdle`. Output: `{"decision":"continue","reason":"..."}` blocks the stop; `{"decision":"stop"}` (optionally with reason) lets it stop.
- Output exactly one JSON line on stdout, exit code 0, nothing on stderr in normal operation.

Each hook module MUST export a pure `evaluate(payload)` (sync or async) returning the output object, plus run `main()` only when `isMain(import.meta.url)`. Tests call `evaluate` directly AND spawn the script for integration.

## 3. Markers (POSIX upstream + PowerShell fusion)

| Marker | POSIX form (upstream, still accepted) | PowerShell form (fusion, documented) |
|---|---|---|
| Zen | `NTG_ZEN_VERIFY=1 <cmd>` or `env NTG_ZEN_VERIFY=1 <cmd>` | `$env:NTG_ZEN_VERIFY='1'; <cmd>` |
| Excavator | `NTG_EXCAVATOR=1 <cmd>` | `$env:NTG_EXCAVATOR='1'; <cmd>` |

PowerShell prefix regex (case-insensitive, anchored at start after optional leading whitespace):
`^\s*\$env:NAME\s*=\s*(['"])1\1\s*;\s*` where NAME is `NTG_ZEN_VERIFY` or `NTG_EXCAVATOR`.

## 4. Role attribution (gates and mcp-role-guard)

Channels, in priority order (first hit wins):
1. payload `roleHint` / `agentName` / identity keys (upstream).
2. transcript structured identity keys (upstream `IDENTITY_KEYS`) and upstream role signature sentences.
3. first inbound task message: the first record that is either `type: "USER_INPUT"` (strip the `<USER_REQUEST>` ... `</USER_REQUEST>` wrapper and everything from `<ADDITIONAL_METADATA>` on) or `type: "SYSTEM_MESSAGE"` whose content contains `[Message] ... content=` (take the text after the first `content=`). If its first non-empty line matches `^NTG_ROLE:\s*([A-Za-z][A-Za-z0-9_-]*)\s*$` the role is group 1 lowercased. Also accept the upstream `## Role\n<role>` form.
4. banner: the first record with `type: "PLANNER_RESPONSE"` whose `content` is a non-empty string; if its first non-empty line matches the same `NTG_ROLE:` regex, that is the role. Only that single record is examined.

Real hub-2.21.0 facts (verified from local transcripts):
- Main-agent transcripts start with `USER_INPUT` (`source: USER_EXPLICIT`), content wrapped in `<USER_REQUEST>`.
- Subagent transcripts start with a `SYSTEM_MESSAGE` whose content is `... [Message] timestamp=... sender=<parentConvId> priority=MESSAGE_PRIORITY_HIGH content=<the Prompt>`.
- Role prompts instruct every primary to emit `NTG_ROLE: <role>` as the first line of its first response, and to begin every `invoke_subagent` Prompt with `NTG_ROLE: <TypeName>` on its own first line.

## 6. Zen PowerShell grammar (N4)

Applies only when the command matches the PS Zen prefix. Body after prefix:
- Deny if the body contains `NTG_ZEN_VERIFY`, any of `` $ ` ( ) { } [ ] @ # > < & ``, the substring `::`, `--%`, or a newline-free empty segment.
- Tokenize with `psTokenize`. Each segment's first token (case-insensitive, strip a trailing `.exe` for git/node/python) must be in:
  - `Get-Content`/`gc`/`cat`/`type` (deny parameters `-Wait`, `-Stream` is allowed)
  - `Get-ChildItem`/`gci`/`ls`/`dir`
  - `Select-String`/`sls`
  - `Get-FileHash`, `Test-Path`, `Get-Item`/`gi`, `Resolve-Path`/`rvpa`, `Get-Location`/`gl`/`pwd`
  - `Measure-Object`/`measure`, `Select-Object`/`select`, `Sort-Object`/`sort`, `Where-Object`/`where`, `Compare-Object`/`compare`/`diff`, `Format-Table`/`ft`, `Format-List`/`fl`, `Out-String`
  - `git` with the exact upstream git rules (same subcommand set and safe long options, short options must not start with `-o`)
  - `node`/`python` with exactly `--version` or `-V`; `node --check <file>`
- Deny any token (case-insensitive) equal to or prefix-abbreviating these PowerShell common parameters: `-OutVariable`/`-ov`, `-PipelineVariable`/`-pv`, `-ErrorVariable`/`-ev`, `-WarningVariable`/`-wv`, `-InformationVariable`/`-iv`, `-OutBuffer`/`-ob`; and `-Wait` (blocks forever). `-Path`/`-LiteralPath` are allowed.
- Excluded on purpose: `ForEach-Object` (`-MemberName` can invoke mutating methods), `Tee-Object`, `Out-File`, `Set-*`, `New-*`, `Remove-*`, `Invoke-*`, `Start-*`.
- Allow reason: `"Marked read-only verification command"`; deny reason: `"Zen permits only read-only verification commands"` (same strings as upstream).
- A command containing `NTG_ZEN_VERIFY` that matches neither the PS prefix nor the POSIX grammar is denied (upstream behavior already denies `$`).
